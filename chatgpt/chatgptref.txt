# **HOSSAM EDSS – Complete Executive Reference Document**

## **1. Project Overview**

**Project Name:** HOSSAM EDSS (Executive Digital Smart Secretary)
**Purpose:** Fully autonomous digital executive assistant for office, NGO, and personal workflows.
**Core Capabilities:**

* Organizing files, emails, and notes automatically.
* Managing reminders and task tracking.
* Preparing and submitting documents (Word, Excel, PDF, PowerPoint).
* Handling external communications (Facebook, Gmail, WhatsApp/Telegram).
* Supporting donor, partner, and NGO engagement workflows.

**Project Rules & Agreements:**

* Confidentiality and secrecy are mandatory.
* AI assistant acts autonomously; minimal questioning.

---

## **2. Technical Architecture**

**AI Intelligence Layer**

* **Ollama:** primary AI engine for language generation.
* **Gemma 2B:** content generation (Facebook, social media).
* **DeepSeek:** tactical shield, memory optimization, system monitoring.
* **ChatGPT:** reasoning, planning, documentation support.
* **Other models:** support and research grounding.

**Workflow Automation**

* **n8n:** central workflow engine.
* ManualTrigger node: starts workflows.
* HTTP Request node: sends prompts to AI models.
* Code node: processes AI output (hashtags, formatting).
* If node: logical branching and output verification.

**Database & Storage**

* PostgreSQL: stores workflow logs and AI outputs.
* File Storage: `D:\hossam-edss\ai-outputs\` for content and logs.
* Google Drive / OneNote: optional cloud sync and archive.

**Containers & Deployment**

* Docker ensures portability and scalability.
* Containers:

  * `hossam-edss-n8n-1` → workflow engine
  * `hossam-edss-ollama-1` → AI server
  * `hossam-edss-postgres-1` → database
* Backup: Windows Ollama installation as fallback.

---

## **3. Operational Procedures**

**Startup**

1. Close heavy apps to save RAM (browsers, ChatGPT desktop).
2. Open PowerShell as Administrator.
3. Navigate: `cd D:\hossam-edss`
4. Restart WSL: `wsl --shutdown`
5. Start services: `docker-compose up -d`
6. Verify workflow engine: `docker-compose ps`
7. Verify AI connection: `curl http://localhost:11434/api/tags`
8. Access n8n: `http://localhost:5678`

**Memory Management**

* Critical RAM < 600MB → heavy slowdown.
* Suggested cleanup: close apps, restart WSL/Docker, or reduce running models.

**Workflow Execution**

* ManualTrigger starts the workflow.
* HTTP Request nodes handle AI prompts.
* Code nodes process outputs (hashtags, character limits, content formatting).
* If nodes validate output readiness.
